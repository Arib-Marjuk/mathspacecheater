mathspace cheater
---
a python script that uses the chrome selenium webdriver 
to solve mathspace questions using google gemini.
may or may not work on other browsers other than chrome, 
but you have to open them with `--remote-debugging-port=9222`

### what currently works:
- follow-up questions
- textbox answers
- mcq answers
- question figures
- picture answers (might not work for more than 1 follow-up question)
- attached tables
- fill in the blanks

### what doesnt work:
- fill in the blank tables

## Installing and Using
- First, download the latest release from Releases
- Then open the main folder run "main.exe"
- Once you see the gui go to the settings from the top
and give your api key for gemini and select the browser you will use
(must be a chromium browser like Google Chrome and Microsoft Edge)
- Click Open Browser button in the app and login to mathspace
- Open a worksheet from the textbook
- Finally, click Start script to start solving problems
